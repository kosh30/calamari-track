# Security

The plugin keeps your Calamari login and a company API key in the system
keyring. If you find a way they could leak, or any other vulnerability,
please do not open a public issue. Report it privately through GitHub's
[private vulnerability reporting](https://github.com/kosh30/calamari-track/security/advisories/new)
instead.

Only the latest release gets fixes. This is a one-person project, so there
are no promises on response times.
